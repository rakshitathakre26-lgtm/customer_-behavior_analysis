# Customer Behavior Data Analytics Project

Overview

This project focuses on analyzing customer behavior data using Python, SQL, PostgreSQL, and Power BI. The main objective is to clean, analyze, and visualize customer data to identify purchasing trends, customer preferences, and business insights.

The project includes:

* Data loading and preprocessing
* Exploratory Data Analysis (EDA)
* SQL querying using PostgreSQL/MySQL/SQL Server
* Interactive Power BI dashboard creation
* Report generation
* Presentation creation using Gamma

⸻

Dataset

The dataset contains customer-related information such as:

* Customer ID
* Age
* Gender
* Category
* Purchase Amount
* Review Rating
* Shipping Type
* Subscription Status

The dataset was used to analyze customer purchasing behavior and trends.

Project Steps

1. Data Loading

* Imported dataset using Python
* Checked missing values and data types

2. Data Cleaning

* Removed duplicates
* Handled null values
* Corrected inconsistent data

3. Exploratory Data Analysis (EDA)

Performed analysis on:

* Customer age groups
* Revenue trends
* Subscription status
* Purchase categories
* Review ratings

4. SQL Analysis

Executed SQL queries using PostgreSQL to:

* Calculate total revenue
* Find top-performing categories
* Analyze customer demographics
* Generate business insights

5. Dashboard Creation

Built an interactive Power BI dashboard with:

* KPI cards
* Revenue charts
* Customer segmentation
* Category-wise analysis
* Subscription insights

6. Report & Presentation

* Created project report
* Designed presentation using Gamma

⸻

Dashboard Features

The Power BI dashboard includes:

* Total Customers
* Average Purchase Amount
* Average Review Rating
* Revenue by Category
* Sales by Age Group
* Subscription Status Analysis

⸻

Results & Insights

Key insights identified from the project:

* Clothing category generated highest sales
* Most customers belonged to young and middle-age groups
* Subscription users contributed significantly to revenue
* Customer ratings showed positive purchasing satisfaction
